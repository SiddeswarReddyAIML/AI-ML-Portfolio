# 🚀 Featured Projects

## 01 — Credit Card Fraud Detection

**FinTech | Machine Learning | Classification**

An end-to-end fraud detection project analyzing **10,000 synthetic credit-card transactions**.

### What I built

- Performed exploratory data analysis
- Investigated fraud patterns across:
  - Transaction timing
  - Transaction amount
  - Foreign transactions
  - Location mismatch
  - Device trust score
  - Transaction velocity
- Analyzed severe class imbalance
- Built a Logistic Regression classification model
- Evaluated performance using ROC-AUC, precision, recall, F1-score, and confusion matrices
- Performed decision-threshold analysis
- Persisted the trained model using Joblib

### Results

| Metric | Result |
|---|---:|
| ROC-AUC | **0.9944** |
| Accuracy | **99.30%** |
| Fraud Recall @ 0.30 threshold | **73.33%** |
| Fraud Precision @ 0.30 threshold | **66.67%** |

### Key takeaway

The project demonstrates the importance of **threshold selection in imbalanced fraud detection**, where maximizing accuracy alone can hide missed fraud cases.

### Technologies

`Python` `Pandas` `NumPy` `Scikit-learn` `Matplotlib` `Seaborn` `Jupyter` `Joblib`

# 02 — Online Retail Data Cleaning & EDA

**Data Science | Data Cleaning | Exploratory Data Analysis**

An end-to-end analysis of the **UCI Online Retail dataset containing 541,909 transaction records**.

### What I built

- Performed data-quality assessment
- Investigated missing values
- Identified and removed exact duplicate records
- Investigated missing customer identifiers
- Analyzed returns and cancellations
- Investigated zero-price transactions
- Investigated negative-price accounting adjustments
- Analyzed transaction-value distributions
- Analyzed monthly sales trends
- Performed geographic sales analysis
- Analyzed product performance
- Analyzed customer purchasing behavior
- Segmented customers by purchase frequency
- Analyzed customer-value concentration
- Investigated customer return behavior

### Key Results

| Metric | Result |
|---|---:|
| Original records | **541,909** |
| Cleaned records | **536,639** |
| Exact duplicates removed | **5,268** |
| Identifiable customers | **4,372** |
| UK share of transaction value | **84.01%** |
| Top 10% customer value share | **60.10%** |
| Frequent customers | **537** |
| Frequent-customer value share | **58.78%** |

### Key takeaway

Customer value is highly concentrated: only **12.28% of identifiable customers** were classified as frequent customers, yet they contributed approximately **58.78% of identifiable-customer transaction value**.

### Technologies

`Python` `Pandas` `NumPy` `Matplotlib` `Seaborn` `Jupyter` `Excel`
